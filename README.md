## 🚀 Installation and Setup

1.  Clone the repository:
    ```bash
    git clone https://github.com/Kamdinee/portfolio.git
    cd portfolio
    ```

2.  Install dependencies
    ```bash
    npm install --legacy-peer-deps
    ```

3.  Start the project:
    ```bash
    npm start
    ```
